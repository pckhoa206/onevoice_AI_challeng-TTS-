⚖️ Phân Định Phần Cứng Trung Thực: CPU Host vs Qualcomm Hexagon NPU

Chuẩn Công Nghiệp Co-Processing

Hệ thống không chạy "100% NPU thuần túy" vì các tác vụ chuỗi ký tự (String) không tối ưu trên NPU. Thay vào đó, áp dụng cơ chế Đồng xử lý không đối xứng (Asymmetric Co-Processing):

🧠 Hexagon HTP NPU (~82.5% FLOPs) Tính toán nặng

  • Neural Vocoder (57.5%): Chạy 100% trong SRAM NPU (43.3 ms).
  • Vector Estimator (15.0%): Khử nhiễu Flow ODE trên phần cứng.
  • Text Encoder (8.0%): One-Hot GEMM trên Systolic Array (7.2 ms).
  • Duration Predictor (2.0%): Dự đoán nhịp độ âm thanh (5.4 ms).

💻 CPU Host / DSP (~17.5% FLOPs) Điều phối I/O

  • QNN Tokenizer (2.5%): Bóc tách Hangul Jamo & tra bảng Flat Table (4.3 µs). Không đưa lên NPU do NPU thiếu phép `Mod`.
  • Vòng lặp ODE (5.0%): CPU host kích hoạt 5 bước suy luận NPU.
  • DMA & Ghi File WAV (10.0%): Đọc bộ đệm âm thanh qua FastRPC bus.
